# Gemini 3.8 Flash High consultation

Requirements: Antigravity desktop with the requested model, a supported native computer-use capability, and Python 3.10+ for optional offline checks. macOS native interaction is not yet verified by this package.

Obtain one independent assessment, preserve the original answer, and verify its claims locally. The controller owns decisions and subsequent implementation.

An explicit request to use this skill authorizes sending the necessary question and evidence to Antigravity and writing the named consultation outputs. Automatic skill selection alone does not authorize a new external disclosure. Honor existing user authorization; do not ask for it twice. This does not authorize product edits, commands in the adviser, installs, publication, or security changes.

## Route and verify

Read the installed native computer-use capability's current documentation before operating the app. Discover available tools on the current host. Windows and macOS may expose different APIs: never assume a Windows-only runtime works on macOS. A browser tool lacking native APIs is not proof that a separate native capability is unavailable. If no supported native capability exists, prepare the packet and clearly report `NOT_SENT`; do not substitute API, CLI, CDP, hidden session data, or browser chat.

Read [native workflow](references/native-workflow.md) for the bounded app interaction and recovery procedure. Verify **Gemini 3.8 Flash High** in the current selected model control and picker immediately before dispatch. Separate family and effort controls must show Gemini 3.8 Flash and High. A Fast badge, model menu listing, or response self-description is insufficient. Do not substitute a different version or level. Reopen an unclear picker once; report the observed limitation if still unresolved.

Resolve the owning project's existing absolute root and read its applicable instructions. Record its branch and HEAD, or non-Git/unborn status, through ordinary local read tools. Reuse its app project and preserve other conversations and drafts. Record Local/remote state, additional roots, and inherited context. Root verification accepts either a visible exact native path or a native read of a unique request marker at the controller-verified exact path; label the evidence type accurately. A basename or prompt path alone is insufficient. One bounded recovery is enough; do not loop through Explorer, Finder, IDE, or permission dialogs to prove the same path.

## Prepare neutral, bounded evidence

Read [packet template](references/context-packet-template.md). Use the owning project's existing review location, normally `docs/reviews`, with unique request/adviser filenames. Reuse original inputs instead of copying the repository or creating one project per adviser. Specify exact allowed files and exact writable report/completion files. Existing neighboring reports are not implicitly readable.

Preserve the artifact, user goals, constraints, facts, contrary evidence and unknowns. Exclude the controller's verdict and previous reviewers' opinions from the initial review. Include actual content or files the native adviser can read, not only paths. Record exposure to app memory, project rules and open files as present, absent with evidence, or unknown; a new chat does not prove isolation. Require content-specific references or visible reads for essential artifacts.

Run `scripts/check_packet_safety.py` on the exact outgoing UTF-8 packet and selected text. Inspect the material too: the scanner is a heuristic, not a privacy guarantee. It reports credential types and locations without echoing source values. Remove actual secrets only from an outgoing copy. Do not send unrelated private history, raw media, credentials or a whole repository by default.

## Dispatch once and collect

Read [delivery protocol](references/delivery-protocol.md). Default to native file delivery: the adviser reads the shared packet and writes its complete first answer to the named report, then writes completion JSON last. Product files remain read-only. Do not paste a long packet if native reads work.

Keep a controller-only record with `NOT_SENT`. Verify current app/project/model, complete rendered wrapper, attachments and prompt focus. Set `UNKNOWN` immediately before clicking Send once; set `SENT` only after observing the submitted request. For `UNKNOWN` or `SENT`, recover the same conversation and never resend because a tool timed out. Serialize native UI actions across concurrent advisers. Use bounded waits no longer than 60 seconds and keep the user informed.

Completion requires the intended target and evidence, visibly stopped generation, no pending tool/approval request, the full original answer, and the exact unique sentinel as its final nonempty line. In file mode run the collector on the exact named outputs after observing the UI stop. Its stable-byte receipt proves protocol integrity, not that the model read every file or that its claims are true.

If native file access fails, preserve the request and collect the full answer from that same chat using supported native export or UI text. Do not resend or ask the model to reconstruct an old answer. Never use an AI composer as a clipboard intermediary. Reacquire a truncated same-turn response once; if still incomplete, report that limitation. Never modify permissions or rewrite adviser output to obtain a PASS.

Preserve the independent answer before any informed follow-up. Report requested/observed model and effort, root evidence and revision, conversation locator, dispatch/transport/collection status, meaningful findings and what local verification supports. Keep generation, collection, protocol validation and factual review separate. Model agreement is not factual validation. Apply changes only within the user's authorized scope.
